# WGame UV 检查助手

Blender 5.2 中文插件。位置：**UV 编辑器或三维视图 → N 侧栏 → WGame UV**。

## 使用

### 拖入贴花素材（1.11.0）

在图像编辑器的 **N 侧栏 → WGame UV → 贴花**，把图片从资源管理器拖到侧栏。
每次一张 PNG、TGA 或 TIFF；透明 PNG 保留 Alpha。拖入只选择素材，保留当前底图、绑定和 UV。
成功或失败原因留在“拖入贴花素材”框内；二维画布继续点“摆放已加载素材”，三维投射继续点“开始预览”。
已有浮动选区或预览时，请先确认或取消再拖入。同路径复用已加载素材并保留内存修改；不同目录同名分别加载。
多文件拖入明确拒绝，不会只导入其中一张。直接拖到中央画布仍走 Blender 自带打开图片的行为，请使用本侧栏。

### 柱面闭环展开（1.9.5）

方柱或圆柱的一圈侧面，在 **保持连续 → 从选中面生成 UV 岛** 时自动识别两个分离端环，
仅在临时展开副本里添加一条连接两端的纵向切缝，再展开为连续带状岛。选侧面即可，顶盖和底盖留在选区外。
原模型已有切缝会传给展开器；已有纵向切缝时优先使用，不再额外切一刀。
平面垫圈等带孔区域保持孔洞；全封闭或非流形选区仍需先选开放区域或使用“自动切分”。
只更新选区 DetailUV，原网格接缝标记、PaletteUV、未选面和模型几何不变，可撤销。
`tests/test_band_unwrap.py` 验证方柱、三角化侧面、圆柱、手工切缝和平面圆环，
检查连续单岛、无重叠、矩形带形状及源数据保持。

### 绘制后继续制作 UV（1.9.2）

底色或发光绘制后，图片窗口可能仍是 Paint 模式。把模型切回编辑模式并选中面，再点
**制作 → 从选中面生成 UV 岛**，工具会自动把当前图片窗口切回 UV 编辑显示，保留正在查看的图片、绘制像素及未选中区域的 UV。无需重复切换 UV Editing 工作区。
仍需一次编辑一个网格；「保持连续」遇到封闭或非流形选区时继续提示选择开放区域或明确使用「自动切分」。

### 圆形化（1.9.0）

- **制作 → 选中 UV 岛圆形化**：将完整单边界岛的外圈整理成圆，保持边界包围盒中心与
  边界多边形面积，再以固定边界作内部平滑。只改 DetailUV/Work，不改模型；
  有孔、多圈边界、固定点或退化边界会提示取消。强度 1 为完整圆整。
- **模型 → 圆整选中模型顶点**：默认 **圆面（含内部）**，适合眼球正面的圆形面片。
  在三维视图用面选择选中完整圆面（含内部），整理圆形外边界并平滑内部到拟合平面。
  **圆环边界**用于只选一圈边界顶点；**球面**只用于真正的立体球体表面。
  不改 UV、拓扑或权重；共用边界顶点的相邻面会随几何移动。
  模型含形态键或共享网格时取消，避免影响表情/其他对象。
- 两者均需要单网格编辑模式、支持强度调节和撤销；先结束贴图浮动预览。
  UV 圆整会改变图案对应位置；模型圆面圆整会改变真实几何并使选区趋于平面。

### 二维画布编辑（1.8.0，默认）

“贴花”页默认使用 **二维画布**，三维投射保留在旁边的辅助模式。
先打开细节画布，再选择：

- **导入素材并摆放**：选择 RGBA 图片后，浮动素材直接出现在左侧画布。
  目标是图像编辑器当前显示的图片，按钮上方会显示“目标画布”；贴底色时选择底色细节图，贴发光时选择发光遮罩。二维编辑不要求所有面的材质都绑定 DetailUV 图片，也可先整理画布再给模型展开 UV。未显示图片时才从模型已映射的 DetailUV 面推断唯一画布。
  文件窗口保留上次目录并清空文件名，需点选具体的 PNG、TGA 或 TIFF 图片；不会沿用当前制作文件的 `.blend` 名称。未选择图片、路径不存在或文件类型不支持时，会在开始摆放前提示，保留当前画布。三维投射的“选择贴花素材”共用此检查。
  已加载素材可用“摆放已加载素材”。初始位置在画布中心。
- **框选移动**：在左侧图片拖出矩形，提取像素为浮动选区，原位置在预览中清为透明。
- **框选复制**：同样框选，但保留原位置。
- 浮动时左键拖动移动；按 S 后移动鼠标缩放、按 R 后移动鼠标旋转，左键结束该次变换。
  侧栏可精确输入像素位置、比例和角度。Enter / 确认合并才写入原图；Esc / 取消恢复显示。
- **撤销二维编辑**：最多 8 步且受 256 MiB 历史预算限制，至少保留最近一步。
  若此后原图被其他绘画操作修改，拒绝覆盖这些新改动。重新打开文件不保留历史。
- **保存细节图**：确认后保存；沿用已有 PNG 备份流程。浮动期间必须先确认或取消。

预览使用独立的临时图片，图像编辑器、材质图像节点和绘制画布临时指向预览，
因此左右同步显示，原图像素保持不变。结束后恢复原绑定。
同一细节图片的其他使用者也会显示预览及最终结果。移动到画布外的部分按画布边界裁切。
本版是矩形选区和一个浮动层，不提供永久多图层或套索。
期间中键平移/滚轮缩放可用，左键由变换操作接管；不需要面遮罩。
热更、禁用插件或读取文件会取消未确认预览。保存 Blend 时也会自动取消未确认浮动预览，避免将临时图片绑定写入文件。

### Texture Paint 绘制流程（1.7.0）

UV 展开完成后，在“制作”页点击 **完成 UV → 进入细节绘制**，或在“贴花”页点击
**进入细节绘制**。自动切到现有 Texture Paint 工作区（若工作区被删除，则在当前布局进入绘制模式），
激活 DetailUV、将材质实际使用的细节图设为单图画布，并开启面遮罩。
编辑模式原来选中的面会保留；没有选区时进入后需选择接收区域，不会擅自全选。
左侧图像编辑器同步进入 Paint 并显示目标图；两个面板切到贴花页。

贴花支持 Texture Paint 面遮罩和原编辑模式两种入口，预览/绘入/撤销无需再回编辑模式。
图像编辑器处于 Paint 时同样可以找到 WGame UV 面板。可用原生笔刷继续补画和擦除。
切换只改变工作区、模式和画布设置，不更改 UV、像素或材质连接，也不自动保存文件。
旧版说明中的“必须在编辑模式贴花”已由此替代；变形修改器限制仍适用。接收面的 DetailUV 可以跨出 0–1，贴花预览和实际绘入均裁切到目标画布，图片外不绘入。

### 页签布局（1.6.1）

面板名称为“UV 与贴图助手”，顶部固定版本/热更新/当前 UV。
四个页签：**制作**（选面生成、松弛、分开、打包）、**检查**（棋盘格、拉伸、重叠）、
**贴花**（素材、投射预览、绘入、撤销、保存）、**通道**（三通道整理、重做替换、旧版清理）。
UV 编辑器与三维视图的页签独立，默认分别为制作/贴花；热更新保留页签选择。
下文提及的操作请在对应页签中查找。

### 素材贴花（1.6.0）

1. 在右侧模型的编辑模式选中接收面，正对该区域调整视角；关闭棋盘格。
2. 点击 **选择贴花素材**，选一张带透明背景的 RGBA PNG。
3. 点击 **开始预览**：锁定当前视角的平面投射方向，只在选中面上生成临时预览。
4. 调整水平/垂直位置、大小、旋转、透明度。水平/垂直值以选区投影宽度为单位。
   可以转动视图检查；转动不会改变已锁定的投射方向。取消后重新预览可换方向。
5. 点击 **确认绘入** 写到原材质直接使用 DetailUV 的图片；或 **取消预览**。
6. **撤销上次贴花**恢复最近一次贴花前整张画布（会覆盖此后在该图上的其他绘画）。
   只保留一步，重新打开文件后不保留；使用此按钮而非依赖 Ctrl+Z 撤销图像像素。
7. **保存细节图**写入现有 PNG 路径，覆盖前在同目录保存带时间戳的磁盘备份。
   没有路径时需先在图像编辑器另存为 PNG；本工具不自动保存 Blend。

目标材质需要有一张图像纹理由 UV Map 节点直接读取 DetailUV。
多张目标图片须分批处理。源图和目标不能相同，需要 RGBA、相同色彩空间、普通二维图片，
本版最大 4096 像素；不支持 UDIM、视频、跨曲面包裹或自动遮挡消除。
只按选面投射：选中的背面也可能接收，请只选需要的接收面。
**共享 UV 的其他面会显示相同图案**，因为它们读取同一画布位置；本工具不自动拆分重叠。
选区必须有非退化、数值有效的 DetailUV；允许跨出 0–1，无需先打包。整面 `(-1,-1)` 留空仍需先展开。三维贴花只写入目标图片范围内的像素，完全没有覆盖画布时会提示调整位置；预览也按相同范围裁切。
本版按编辑网格处理，活动的变形/几何修改器会要求先关闭，不擅自应用它们。
热更新、禁用插件或载入文件会取消未确认的临时预览；已绘入图片的内容保留。

### 三个正式 UV（1.5.0）

正式顺序固定为 **UV0 → PaletteUV → DetailUV**：UV0 保留占位，PaletteUV 取色，
DetailUV 承载所有细节（包括脸）。Unity 当前导入检查按索引 1 读色板、索引 2 读细节，
因此顺序不能任意调换；本次未修改或重新验收 Unity 渲染链路。

- **编辑 DetailUV**：一键切到正式细节通道。
- **整理为三个正式 UV**：关闭棋盘格后执行，按固定顺序整理并激活 DetailUV。
  FaceDetailUV 只补入 DetailUV 的 (-1,-1) 空白角点；两边均有不同坐标时取消并报冲突数量。
  将原材质直接引用 FaceDetailUV 的节点改为 DetailUV，先复制材质以隔离其他对象。
  其他多余通道仅在全空或数据已包含在 DetailUV 且无引用时删除。
  独立的 Work/Old 布局需要先通过正式替换和删除旧版处理，不自动丢弃。
- 生成岛、松弛、打包和留空只允许 DetailUV 或 DetailUV_Work 临时通道。
  UV0/PaletteUV 不参与细节修整；旧 FaceDetailUV 通过整理功能迁移。
- 临时 Work/Old 仍可用于重做和回退，收尾后回到三个正式通道。
  整理不合并图片、不重投射已有纹理，不自动保存模型。

### 热更新（1.4.0）

版本号旁的 **热更新插件** 同步本机 deployment.json 指向的仓库源码，再延迟重新加载。
更新前校验全部 Python 文件语法，部署目录保留 `.previous` 副本。
保留场景设置、活动 UV、UV 坐标和棋盘格显示状态，不保存角色或清空展开。
界面显示成功版本或失败原因。独立 ZIP 安装没有部署记录时，仅重载安装目录现有代码。
热更不会联网下载版本；只有仓库代码更新后才会加载新的实现。

### 正式细节 UV 收尾（1.3.0）

- 关闭棋盘格，选择制作好的活动 UV，点击 **将当前 UV 设为正式 DetailUV**。
  原 DetailUV 保留为 DetailUV_Old（有同名时自动加后缀），新通道接替为 DetailUV；
  WGame 材质的 Detail_UV 节点同步更新，材质先复制以免影响其他对象。
  其他直接 UV 节点对旧通道的引用保留为旧版引用，不擅自迁移。
- 检查效果后，在“旧版 UV”选择备份，点击 **删除旧版细节 UV**并确认。
  只允许删除由本工具记录的备份；材质/节点组/修改器仍引用、默认渲染 UV、
  动画/驱动需要人工核查等情况会阻止删除。
- UV0、PaletteUV、FaceDetailUV 受保护。网格数据多用户、嵌套节点引用或修改器引用
  无法安全迁移时明确取消。仅适配直接包含 Detail_UV 节点的 WGame 细节材质。
- 按钮兼容对象/单网格编辑模式，支持撤销，不重投射贴图、不保存 Blend。

### 从选面开始制作（1.2.0）

1. 编辑模式在三维模型上切到面选择，选择想绘制的一片区域。
2. 点击 **从选中面生成 UV 岛**：忽略旧 UV 分岛，对该选区重新展开，
   放在未选中 UV 的右侧，并在 UV 编辑器框选显示。没有其他有效区域时从第一格开始。
3. 开棋盘格检查；再选择下一片区域，重复生成。最后统一打包。
4. 不再需要的区域用 **选中面取消细节 UV**，将选中面的全部角点置为 (-1,-1)。
   不再把“只处理选中点”的旧操作作为主按钮；旧操作仍可通过搜索使用。

需要完整重做时，点击 **新建空白细节 UV（保留旧版）**，新通道名为
DetailUV_Work（重名由 Blender 添加后缀），旧 UV 不删除，新通道全部留空并设为活动通道。
**新通道不自动改变材质取样通道**；制作时可使用棋盘格，正式使用时再将细节材质
的 Detail_UV 节点指向新通道。已有贴图也不会自动重投射到新布局。

开放的拓扑圆盘选区使用原生 Unwrap，互不连接的部分分别展开。
环形、封闭或其他复杂区域自动使用 Smart UV Project 切分，可能生成多座岛；
自动展开不保证所有形状都无拉伸。原模型切缝标记、拓扑、其他 UV 坐标均不修改。
只处理模型上选中的完整面，不自动扩展到旧岛。固定 UV 点会阻止生成；显式取消细节 UV 会清除选中面的坐标。
需要 UV Editing 工作区，一次编辑一个网格。操作可撤销，不自动保存角色。

### 棋盘格与拉伸显示

1. 选中角色网格，进入 UV Editing 工作区。
2. “当前 UV”直接读取活动 UV，双向同步。选择 UV0、DetailUV 或 FaceDetailUV 会切换活动通道；
   在 Blender 原生 UV 列表切换也会同步面板和已开启的棋盘格。切到 PaletteUV 自动关闭检查。
3. 点击“显示棋盘格”。UV 编辑器背景和模型使用同一张检查图片；三维视图自动切到材质预览，显示整个目标对象的格子，
   编辑模式也可用。选择黑白／蓝黄和每边格数后，点击“更新棋盘格”。
4. 点击“关闭棋盘格”恢复所选对象原材质；“关闭所有棋盘格”也覆盖未选中的对象。
5. 编辑模式选中需要检查的面，点击“角度”或“面积”，在 UV 编辑器查看原生热力图。
   蓝色表示差异低，红色表示差异高。面积是相对面积差异，不等于绝对像素密度。
   如果显式指定检查 UV，拉伸按钮会将其设为活动 UV，方便查看；不改变渲染 UV。

## 边界

- 不改 UV 坐标、拓扑、色板数据、网格材质槽、面材质索引或原材质节点。
- 棋盘格采用附加在修改器栈末尾的几何节点检查材质；默认不参与渲染。
  这仍是 Blender 修改器，某些导出器会采样视口求值结果，因此**导出前关闭所有棋盘格**，
  不要手动应用检查修改器。插件未接管既有导出工具。
- 棋盘格针对整个选中网格／编辑中的网格，不限于选中面；无 UV 或 PaletteUV 会提示并取消整批操作。
- 拉伸图在 UV 编辑器中显示，不是三维模型热力图；无 UV 编辑器时提示打开 UV Editing。
- 同一会话关闭最后一个棋盘格会恢复自动切换前的视口着色（用户已经改成其它模式时保留选择）。
  同时恢复 UV 编辑器原图；用户手动换成其他图片时保留该选择。
  更新格数／颜色不会覆盖原图恢复记录。跨会话关闭后可手动从图片列表选回原图。
  保存并重新打开含棋盘格的 Blend 后仍可关闭检查修改器，但不追溯前一会话的视口模式。
- 开关和修改器操作支持 Blender 撤销；不自动展开、打包或保存角色文件。

## 安装

扩展 ZIP：编辑 → 偏好设置 → 获取扩展右上角菜单 → 从磁盘安装，选择 ZIP。
也可以使用 `install.ps1` 部署为传统插件，然后在插件列表启用
“WGame UV 检查助手”。两种方式择一，避免重复安装。

## 验证

## UV 岛修整（1.1.0）

在编辑模式一次编辑一个网格，使用当前活动细节 UV。
检查 UV 字段如显式指定了不同通道，会要求先切换，避免改错通道。

- **检查全部有效岛重叠**：使用 Blender 原生重叠检测，选中涉及重叠的完整岛；
  不改坐标。包括独立岛之间的重叠及原生检测能发现的岛内重叠，不推断是否有意复用。
- **分开选中岛**：完整岛平移到现有 UV 右侧，并排留出间距，不缩放或旋转。
  可暂时超出 0–1，不解决岛内部的自重叠。
- **松弛选中岛**：原生 Minimize Stretch，处理后恢复各岛包围盒中心和总 UV 面积。
  松弛可能改变边界和内部形状，不保证任意拓扑都能改善；固定点存在时取消并提示。
- **打包选中岛到 0–1**：原生 Pack Islands，允许缩放旋转，不合并重叠。
  方形贴图尺寸与像素间距换算为 UV 间距。**不避让未选中岛**；需要全局无重叠时，
  选择全部要放入此贴图的有效岛一起打包。

只选岛的一部分时扩展为完整岛。存在隐藏面的岛整岛跳过；PaletteUV 禁止修改，
零面积面及 (-1,-1) 留空坐标不进入修整。松弛、分开和打包都会改变现有贴图对应关系，
不重投射已有贴图。各操作支持 Blender 撤销；不自动保存角色。
原生计算在临时场景的副本网格上进行，只写回目标 UV 坐标，结束后清理临时数据。

## 1.3.2 通道同步

“当前 UV”不再保存独立覆盖值。界面、活动 UV 与棋盘格采样通道同步；
空字符串赋值仅为兼容旧内部调用，不切换通道。本文较早版本提到的“留空/检查 UV 与活动 UV 不一致”流程已由此替代。

## 1.5.1 连续选区展开修正

默认“保持连续”：有边界的连续流形选区使用 Unwrap，允许孔洞，不再根据欧拉特征将嘴唇等区域误送入 Smart Project。
封闭或非流形选区给出提示；只有明确选择“自动切分”才使用 Smart Project。
以上替代旧版关于环形区域自动切分的说明。已用当前嘴唇 119 面选区副本验证生成一座完整岛。

## 1.8.1 变换与 UV 岛参照

框选/导入后的浮动层支持移动、统一缩放、横纵独立拉伸、倾斜变形及旋转。
橙色角点可拖动，以中心为基准独立改变宽高；R 旋转，侧栏可精确输入各参数。
框选和浮动期间默认叠加蓝色 DetailUV 岛边界（跳过留空区），可用“显示 DetailUV 岛轮廓”开关控制。
UV 线条仅供定位，不会写进图片；本次变形是像素仿射变换，不修改 UV，不包含四角透视扭曲。

## 1.8.2 交互性能

左侧浮动素材由 GPU 绘制，不再每次变换都合成/上传整张画布。UV 轮廓批次按视图缓存。
右侧模型预览拖动时按最长边 256 计算，停下后按 512 提高预览清晰度，更新节流到最多约 10 次/秒。
最终确认独立地使用完整画布和原始素材合成，代理预览不参与保存结果。
本机 2048 画布/1024 素材示例：完整合成及上传约 791ms，移动代理约 37ms；这是处理耗时而非整体帧率。

## 1.9.1 二维撤销与重做

二维画布提供 Ctrl+Z / Ctrl+Shift+Z 及对应按钮。浮动期间逐步撤销/重做移动、缩放、旋转、拉伸；
撤销到初始状态后继续撤销可移除浮动导入，重做可恢复它。确认合并后撤销/重做实际像素修改。
新提交会清除旧重做分支；取消预览不改原图。像素历史仍受最多 8 步/256MiB 预算限制，
浮动变换最多 64 个检查点。图片被其他工具修改后拒绝覆盖新改动。
快捷键仅在二维画布页的图像编辑器生效，不接管右侧模型撤销；重新打开文件不保留历史。

## 1.9.3 素材文件选择

二维导入与三维贴花选择共用图片路径检查；打开文件窗口时保留目录并清空文件名，避免导入器继承当前 `.blend` 名称。
`tests/test_image_import.py` 需使用图形 Blender（`--factory-startup --python`，不加 `--background`）：
验证初次打开、残留路径、两个真实文件窗口、中文大写扩展名 PNG 导入、错误路径保护和取消浮动摆放。
结果写入 `.agent/uv-image-import/`；该回归不打开或保存用户的制作文件。

## 1.9.4 二维目标画布

二维操作以图像编辑器正在显示的图片为目标，不再要求模型所有材质都接入细节图；
未显示图片时仅检查已映射的 DetailUV 面，忽略留空的纯色部分。三维投射仍校验接收面。
底色与发光画布由显示图片明确区分，不跟随材质中遗留的活动图片节点；无活动模型时也可整理二维画布。
`tests/test_canvas_target.py` 覆盖混合材质、底色／发光切换、独立画布、缺失目标提示和撤销保持；
`tests/test_image_import.py` 通过真实文件窗口验证导入到含纯色与细节面的模型。
