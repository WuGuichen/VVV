# 000008 原色板合图与制作材质对照（2026-09-20）

## 修正

- 原打包将“一个 UV 岛内跨面出现不同纯色”误判为纹理细节，随后以最大化该岛细节密度为目标，导致只有 41 个面的发束占据整图约 16.7%。现在对已经证明逐面恒定的色板区域按表面积／控制数据需求分配，不再当作手绘纹理。
- 直接识别当前使用的 `PaletteUV → 最近点 sRGB 色板图 → Principled Base Color` 输入，逐面写入原 RGB 值；带实际细节混合或其它颜色图的角色仍走通用烘焙。
- sRGB 图像缓冲区与 PNG 保存按相同编码处理，恒定色格也按原 RGB 字节写入。测试覆盖相反朝向的重合面分别使用黑色／红色，以及保存 PNG 后再次读取的颜色核对。
- 默认预览还原制作端的高光、皮肤散射、环境光与色彩管理；运行时头发／灯光近似作为显式切换模式。骨骼和网格叠加默认隐藏，检查 UV 时可单独打开网格叠加，返回制作恢复原设置。

有颜色的纹素覆盖率不是有效纹素密度：其中包含留边，剩余空间还受不规则 UV 形状影响。头发控制图仍保留现有几何 AO，因此不把所有头发无条件合并成一个色格。

使用同一森林环境、相机、AgX 普通对比及对应 Profile 材质参数渲染源角色与烘焙角色，裙内红色均可见；整图 RGBA 平均字节差约 0.048 / 255，属于当前角色、该视角与该对照环境的结果，不宣称跨渲染器逐像素相同。单纯按几何位置匹配会遇到少量重复面／不同三角化面的歧义，因此同时核对了导出面序。
