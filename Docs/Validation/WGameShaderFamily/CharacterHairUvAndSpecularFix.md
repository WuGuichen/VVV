# 000008 头发 UV 与高光修正（2026-09-20）

## 已确认的问题与修复

- 原根梢单条切缝无法展开部分带孔、连接复杂的头发表面。000008 有 5,409 个三角面回退到碎片展开，形成 341 个头发 UV 岛。
- 保留成功的根梢展开；只为失败区域补充拓扑切缝，并隔离局部相反的面连接。顶点与三角形不做删除或重拓扑，原接缝标记在临时计算结束后恢复。
- 哑光／柔光边界单独分岛，防止 512 分辨率下细三角形采到邻面的分类。最终不是单纯追求最少岛数。
- 专用头发高光原来用固定 0.6／1.0 缩放，绕过了 Profile 的 specular 强度。Unity 主 Shader 与 Blender 预览现在使用同一 Profile 参数：哑光 0.06、柔光 0.18，保留作者的底色和头发形状参数。

## 最终验证

- Blender 画板版本 3.14.18，烘焙器 1.4.0；当前 000008 的临时预览已经重建并打开，未发布到 Unity。
- 同一角色、512×512：头发展开 111 个有效岛，退化／翻折回退面为 0。最初不区分 Profile 边界的实验是 63 岛，但少量细面存在分类错采，因此未采用该实验结果。
- 最终合图有 19 个共享常量格、1 个颜色变化区域及 101 个表面数据区域。它是运行时自动合图，不是手绘用的人体展开布局。
- 与制作网格能建立几何对应的 33,739 个三角面中，旧 512 结果存在 13 个 Profile 采样不符，最终结果为 0；此比较不覆盖无法唯一对应的重复面或不同三角化面。
- Atlas 回归 20 项通过，覆盖带孔头发、分类边界、原几何／接缝保留和既有细节复用／打包场景。烘焙预览回归通过，包含 Profile 高光表接线、来回切换、保存隔离及 Work 文件不变。
- 同光照／相机的黑发对照显示，大片白亮带已收敛为较弱高光；底色不做重画。Unity Shader 无编译消息，Console error 为 0。
- FBX 回读完成，发流数据通过现有格式／有限值／长度检查。不同 UV 布局导出后逐角重建方向的诊断仍有局部差异，本次不宣称所有角点的发流逐值或跨渲染器逐像素一致。
