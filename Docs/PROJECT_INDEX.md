## Conflict Rule

Use the status model in `Docs/README.md`:

1. Source and tests are the implementation truth.
2. Current docs define maintained project facts.
3. Policy docs define current gates and promotion rules, but activity numbers still come from Current docs and machine evidence.
4. Guide docs explain current usage and troubleshooting.
5. Design docs explain intent, but do not override current API docs.
6. ADRs preserve decision history; each file's `Decision Status` determines whether it is operative or rescinded.
7. Archive and Draft docs are never current facts unless promoted into Current / Policy / Guide / Design / ADR docs.
